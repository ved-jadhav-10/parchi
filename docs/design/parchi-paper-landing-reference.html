A drug hidden inside a cold tablet still counts.

Every ingredient is totalled per day across all the brands on the slip, then held against the limit on file.

  • Read the slip

    Brand names and doses are matched the way they are written, misspellings included, and each medicine is split into its ingredients.

  • Add it up

    Each ingredient is totalled across brands, so a drug inside a cold tablet is counted with the one on the next line.

  • Compare

    Totals are held against limits and rules that come from data files, each with a source and whether a pharmacist has signed it off.

  • Alert sparingly

    Three tiers. Interrupts are kept rare, and overriding one needs a reason that is logged.

For e-pharmacies and pharmacy chains.

Your pharmacists already review every order before it ships. Parchi works on the data you already hold, so that review is faster and written down.

  • The whole history, not one slip

    Prescriptions from several doctors go on one timeline. Doses add up only where the dates overlap, and an alert names the doctors and the days.

  • A new kidney result re-checks the order

    When a creatinine arrives, the order is checked again and a short list shows which alerts were added, cleared or moved.

  • The riskiest order first

    Orders are ranked, each with a suggested status: clear, clear with a note, or hold and contact the doctor. The pharmacist decides, and every decision is logged.

  • Fits what you already run

    Catalogue import from CSV, FHIR R4 prescription records in and out, and a JSON check API. Nothing is tied to one vendor, and it runs offline at a store counter.

It informs. The pharmacist decides.

Parchi never approves or blocks a prescription. It shows what is worth a second look, and why, with the source beside it.

  • InterruptAct before dispensing. Kept rare on purpose.
  • InformWorth knowing. No action required.
  • SilentLogged only, collapsed by default.

Measured, not claimed.

Parchi is scored on a set of labelled prescriptions, and against the chatbots a counter might reach for instead. The labels are a draft until a pharmacist has reviewed them, and the benchmark page says so.

  • The same prescriptions, every system

    The engine and each chatbot are given the same slips and scored the same way.

  • Alert load counts

    Alerts per prescription and false alarms on clean ones are measured, because too many alerts get ignored.

  • Every limit has a source

    Dose limits and rules are shown with where they come from, and whether a pharmacist has signed them off. Today they are drafts.

Put it on the counter.

Install Parchi on a phone or the counter PC, or open the review desk for orders that carry prescriptions from several doctors. After the first load it works without a connection.
