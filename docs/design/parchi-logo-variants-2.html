Parchi logo variants, round 2

No R / Rx this time. These lean on the name (P, पर्ची) and on how Hindi is written. Each uses currentColor plus one indigo accent, and none uses a tick.

Variant 01 is a simplified geometric take on the Devanagari letter प, and it should be checked by a Hindi reader before it's used. Variant 06 uses live text and would be converted to outlines for a final file.
