How a prescription is checked

A drug hidden inside a cold tablet still counts. Every ingredient is totalled per day, across all the brands on the slip.

Paracetamol, from three brands (sample)
Dolo 650Crocin Cold & Flu MaxZerodol-P
4,100 / 4,000 mg a day

  1. Read the slip

    Brand names and doses are matched the way they are written, misspellings included, and each medicine is split into its ingredients.

  2. Add it up

    Every ingredient is totalled per day across all brands, so a drug hidden inside a cold tablet still counts.

  3. Compare

    Totals are held against dose limits and rules that come from data files, each with a source and whether a pharmacist approved it.

  4. Alert, sparingly

    Three tiers: Interrupt, Inform and Silent. Interrupts are kept rare, and overriding one needs a reason that is logged.

It informs. The pharmacist decides.

Parchi never approves or blocks a prescription. It shows what is worth a second look, and why, with the source beside it.

  • InterruptAct before dispensing
  • InformWorth knowing, no action required
  • SilentLogged only, collapsed by default

  • Daily totals

    Each ingredient added up across every brand on the slip, against the limit on file.

  • Age and kidney function

    Weight or creatinine is asked for only when a medicine needs it.

  • Interactions

    With a severity and the source it comes from.

  • Duplicate classes

    Two NSAIDs, two PPIs, or any other pair from one class.

  • Banned combinations

    Fixed-dose combinations on the banned list.

Measured, not claimed

Parchi is tested against pharmacist-labelled prescriptions, and against the chatbots a counter might reach for instead.

  • The same prescriptions, every system

    The engine and each chatbot are given the same slips and scored the same way.

  • Alert load counts

    Alerts per prescription and false alarms on clean ones are measured, because too many alerts get ignored.

  • Every limit has a source

    Dose limits and rules are shown with where they come from, and whether a pharmacist has approved them.
